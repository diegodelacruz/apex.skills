# Inicialización en Windows

> **OBSOLETO COMO PROCEDIMIENTO OPERATIVO.** Consulte la [guía canónica de inicialización](inicializacion-automatica-codex.md).

La guía vigente no registra ni elimina servidores MCP, no aplica parches al upstream y no hace handshake. Use `-SkipRemoteProbe` para ejecución local; sin esa opción sólo se sondean perfiles Oracle listos, incluida Producción en modo lectura.
