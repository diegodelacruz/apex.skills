# Complete APEX Delivery Lifecycle

1. Start with `apex-project-bootstrap-final` and create `control-proyecto/`.
2. Apply `apex-environment-alignment` before any edit to an existing page.
3. Mine patterns, design, govern DATA changes, and engineer APEX under the approved baseline.
4. Validate TEST, package release SQL and manifest, then obtain production authorization separately.
5. After approved QA, create the rendered/audited Word manual.

Use `apex-delivery-lifecycle-safe` for the detailed phases and `oracle-data-change-governance-final` for every DATA object change. Record all profile access states and environment decisions without secrets.
