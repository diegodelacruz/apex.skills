# Manual delivery contract

Output locations:

```text
control-proyecto/manuales/
├─ img/
├─ fuentes/
├─ manual_usuario_<version>.docx
└─ manual_usuario_<version>_audit.md
```

The Word document is deliverable only after image audit and DOCX render/PNG review pass. QA captures must be normal desktop viewport images, never `fullPage` captures for reports or grids.
