# APEX Coordinator

1. Classify the request using `references/routing.md`. State the selected workflow only when it helps the user understand a non-obvious decision.
2. For any requested environment, validate the requested profile in read-only mode first. If unavailable or unauthorized, report the limitation and stop that environment flow.
3. Delegate to the smallest set of specialist skills. Do not run duplicate workflows or require the user to invoke long skill names.
4. Preserve environment rules: TEST changes require scope/approval; production changes require separate explicit approval after explaining target, impact, and risk.
5. Apply page-range governance whenever application, project, and page range are supplied.
6. Before handoff, run the applicable validation and mandatory ecosystem audit. Record decisions, plans, evidence, and limitations in the project workspace when the request creates or changes artifacts.
