# Routing table

| User intent | Specialist workflow |
| --- | --- |
| Start a new project | `apex-project-bootstrap-final` → `apex-project-workspace` → `apex-delivery-lifecycle-complete` |
| Application/project/page range | `apex-page-range-governance` |
| Inspect APEX/Oracle, diagnose an error, or investigate slowness/performance | `apex-database-diagnostics`; add `apex-environment-alignment-complete` for existing-page changes |
| Optimize an Oracle object, query, or PL/SQL execution | `apex-database-diagnostics`; add `oracle-data-change-governance-final` only when a change is requested |
| Learn from ZIP exports | `apex-pattern-mining-safe` → `apex-solution-design` |
| Design or edit APEX | `apex-engineering-safe`; add alignment for existing pages |
| DATA object change | `oracle-data-change-governance-final` |
| Export/static QA | `apex-export-qa-safe` |
| TEST/production copy or release | `apex-environment-alignment-complete` → `apex-delivery-lifecycle-complete` |
| Final Word manual | `apex-user-manual` |

Explicitly named specialist skills take precedence when they do not conflict with safety or approval requirements.
